# 商流供应商工作台

一个无需构建步骤的静态演示页面，整合供应商经营工作台与“小商”对话助手。直接在浏览器中打开 `index.html`，或使用任意静态文件服务器预览。

## 已整合功能

- **供应商工作台**：今日待发货、即将超时、在售商品和结算金额等模拟经营指标；订单待办列表与履约表现数据。
- **对话输入**：可在助手输入框键入问题并按 Enter，或点击发送按钮。用户消息会立即出现，模拟回复会在两秒后依据订单、商品或库存关键词返回。
- **快捷问题**：三个快捷提问卡片使用与普通输入一致的发送流程。
- **浏览器语音转文字**：支持 `SpeechRecognition` / `webkitSpeechRecognition`，识别语言为 `zh-CN`。录音时麦克风按钮变红，结果会回填输入框，等待人工确认发送。不支持该 API 时，麦克风会隐藏并显示文字提示。

## 本地预览

```bash
python3 -m http.server 8765
```

访问 [http://localhost:8765](http://localhost:8765)。
